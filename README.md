# PaidBot — Telegram бот для оплаты публикации постов

## Функции

- Автоматическая проверка оплаты по скриншоту (OCR через easyocr)
- Поддержка текстовых и фото-постов
- Публикация в канал @optoviygr
- Автоудаление постов через 24 часа
- Очистка чата после публикации

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python bot.py
```

Или двойной клик на `run.bat`.

## Конфигурация (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| BOT_TOKEN | Токен бота от @BotFather | (обязательно) |
| TARGET_CHANNEL | Канал для публикаций | optoviygr |
| CARD_NUMBER | Карта для оплаты | 4255190154088028 |
| PAYMENT_AMOUNT | Сумма в BYN | 5 |
| POST_LIFETIME_HOURS | Время жизни поста | 24 |
| SUPABASE_URL | URL Supabase проекта | (обязательно) |
| SUPABASE_ANON_KEY | Anon/publishable ключ Supabase | (обязательно) |

## Настройка Supabase (обязательно для анти-дубликации)

Создайте таблицу `screenshots` в Supabase SQL Editor:

```sql
create table if not exists public.screenshots (
    id            bigint generated by default as identity primary key,
    file_hash     text,
    image_hash    text unique,
    text_hash     text unique,
    check_number  text unique,
    file_unique_id text unique,
    user_id       bigint not null,
    created_at    timestamptz default now()
);
create index if not exists idx_screenshots_hashes
    on public.screenshots (file_hash, image_hash, text_hash, check_number);
```

Включите RLS и добавьте политику:

```sql
alter table public.screenshots enable row level security;
create policy "Allow insert" on public.screenshots for insert with check (true);
create policy "Allow select" on public.screenshots for select using (true);
```
